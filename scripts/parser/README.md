# Парсер Трудового кодекса РФ

Парсер для извлечения статей ТК РФ с сайта [ConsultantPlus](https://www.consultant.ru/).

## Возможности

- ✅ **⚡ Параллельная обработка** - парсинг батчами через `asyncio.gather()` (**5x ускорение!**)
- ✅ Асинхронная загрузка статей через Playwright
- ✅ Извлечение полной иерархии (Часть → Раздел → Глава → Статья)
- ✅ Определение статуса статьи (действующая/утратила силу/приостановлена)
- ✅ Прогресс-бар для отслеживания процесса
- ✅ Автоматическое сохранение промежуточных результатов (checkpoints)
- ✅ Поддержка продолжения с любой статьи

## Структура модулей

```
scripts/parser/
├── __init__.py           # Инициализация пакета
├── main.py               # Точка входа (главный скрипт) ⚡
├── fetcher.py            # Загрузка списка статей с главной страницы
├── hierarchy.py          # Парсинг иерархии ТК РФ
├── article_parser.py     # Парсинг отдельных статей (Playwright)
└── utils.py             # Сохранение checkpoint'ов и результатов
```

## Требования

- **Python 3.11+** (для `TaskGroup` и `Semaphore`)
- Playwright, httpx, beautifulsoup4, tqdm

## Установка зависимостей

```bash
# Проверьте версию Python
python --version  # Должно быть >= 3.11.0

# Установите зависимости
pip install playwright httpx beautifulsoup4 tqdm
playwright install chromium
```

## Использование

### Базовый запуск (все статьи, параллельно)
```bash
cd scripts/parser
python main.py
# По умолчанию: batch_size=5 (оптимально)
```

### Тестирование на первых 10 статьях
```bash
python main.py --limit 10
```

### Продолжить с определенной статьи
```bash
python main.py --start-from 50
```

### Настройка параллелизма
```bash
# Консервативный режим (медленный интернет)
python main.py --batch-size 3

# Агрессивный режим (быстрый интернет + мощный ПК)
python main.py --batch-size 7
```

### Изменить путь к выходному файлу
```bash
python main.py --output ../../custom_output.json
```

### Все параметры
```bash
python main.py \
  --limit 100 \
  --start-from 0 \
  --batch-size 5 \
  --output ../../data/tk_rf_articles.json \
  --data-dir ../../data \
  --checkpoint-interval 10
```

## Параметры командной строки

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `--limit` | Ограничить количество статей | Все статьи |
| `--start-from` | Начать с указанной статьи | 0 |
| `--batch-size` | Размер батча для параллельной обработки ⚡ | 5 |
| `--output` | Путь к выходному файлу | `../../data/tk_rf_articles.json` |
| `--data-dir` | Директория для checkpoints | `../../data` |
| `--checkpoint-interval` | Интервал сохранения checkpoints | 10 |

## Статусы статей

- `active` - действующая статья
- `abolished` - утратила силу
- `suspended` - приостановлена

## Производительность

### Сравнение скорости

| Режим | Время на статью | Время на 424 статьи | Ускорение |
|-------|----------------|---------------------|-----------|
| Последовательный | ~3 сек | ~30 минут | 1x |
| **Батчи (5 статей)** | **~0.6 сек** | **~6 минут** | **5x** ⚡ |

- **Оптимально:** `--batch-size 5` (по умолчанию)
- **Консервативно:** `--batch-size 3` для медленного интернета
- **Агрессивно:** `--batch-size 7` для быстрого интернета
- Checkpoint каждые 10 статей

## Восстановление после сбоя

Если парсинг прервался, используйте checkpoint:

```bash
# Смотрим последний checkpoint
ls -lt ../data/checkpoints/

# Продолжаем с нужной статьи
python main_new.py --start-from 100
```

## Troubleshooting

### Ошибка "Chromium not found"
```bash
playwright install chromium
```

### Timeout при загрузке
- Проверьте интернет-соединение
- Увеличьте timeout в `article_parser.py`

### Короткие тексты в результатах
Некоторые статьи могут содержать мало текста (отсылки, утратившие силу). Минимальная длина - 50 символов.
